## Architectural Principles

1. **Layered Diagnostic Granularity:** Self-service documentation must mirror system layers (Theme → Color → Accent Tone → Typography → Motion) rather than presenting a flat list of disconnected articles.
2. **Deterministic Escalation Contracts:** When customer self-service fails, documentation must specify the precise reproduction payload, logs, and diagnostic path so Tier-2/Tier-3 engineers do not repeat baseline discovery (cross-linked to [Proof 3](../01-support-technical-ops/incident-investigation/)).
3. **Runbooks as Living Systems:** Internal technical runbooks must pair narrative explanations with copy-paste verification commands, schema assertions, and failure recovery protocols.
